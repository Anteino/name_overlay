# name_overlay
A name overlay to be used in OBS

The displayed name can be entered live with the text form below the overlay (use right-click on the overlay and choose interact option in OBS), although this is buggy (you can't see what you are typing but it works.

Names can also be encoded in the url as follows:

https://anteino.github.io/name_overlay?name=yourname

Remember, to URL encode a
 - space, use %20
 - enter/newline, use %0A

To encode below text:

This is
Silly Goose

The URL would look as follows: https://anteino.github.io/name_overlay?name=This%20is%0ASilly%20Goose
